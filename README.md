# Тренажёр действий при чрезвычайных ситуациях (ОБЗР, 8–11 класс)

Учебный веб-тренажёр с ветвящимися сценариями для отработки действий при шести типах ЧС: пожар, атака БПЛА, цунами, химическая/радиационная авария, кислотные дожди, аварии на системах жизнеобеспечения.

## Запуск

1. Скачайте папку проекта.
2. Откройте `index.html` в современном браузере.
3. Сервер и установка зависимостей не требуются.

## Структура

- `index.html` — разметка экранов.
- `style.css` — оформление и адаптивность.
- `script.js` — данные сценариев и логика.
- `пояснительная_записка.docx` — текст курсовой работы (вне репозитория или в папке docs).

## Данные и хранение

История прохождений сохраняется в `localStorage` под ключом `emergencyTrainerHistory`. Данные доступны только в том браузере, где проходили сценарии; при очистке хранилища записи удаляются. Персональные данные не собираются, секретов в коде нет.

## Применение ИИ

- **Задача:** структура ветвящегося сценария «Пожар в школе».
  **Запрос:** «Предложи 3 шага с вариантами и объяснением последствий для школьника».
  **Проверка:** каждый шаг сверен с памяткой МЧС; шаги без подтверждения удалены.
  **Исправления:** добавлено требование «не прятаться», уточнены формулировки.

- **Задача:** черновик функции отрисовки шага.
  **Проверка:** код запущен в браузере; исправлена ошибка повторного нажатия (блокировка кнопок).

- **Задача:** редакторская правка абзацев записки.
  **Проверка:** факты и ссылки сверены с источниками; неподтверждённые утверждения удалены.

## Известные ограничения

- Нет синхронизации между устройствами.
- Сценарии не заменяют практическую эвакуацию и инструктаж.
- Экспертиза содержания преподавателями ОБЗР не проводилась.
